# TerminalPane extraction — the moving map (Stage 1)

What moves where when `App.tsx` (~640 lines) is de-singletonized. Line numbers are approximate
anchors (post chrome-tabs-and-panes); match by the named refs/effects, not offsets. Three
destinations: **TerminalPane** (per-instance), **App** (global/control), **SPLIT** (one concern
becomes two pieces).

| Concern (anchor in App.tsx)                                                               | Today                                               | Moves to                                                                                                                                                                                                                                                                                                                      |
| ----------------------------------------------------------------------------------------- | --------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `wsRef` + per-session socket effect (`useEffect` on `[instance, sessionId, …]`, ~215–305) | one WsClient, swapped per session                   | **SPLIT** — TerminalPane gets a per-`sessionId` DATA socket (binary, `snapshot`, `exit`, `ready` cols/rows, sends binary + `resize`); App gets a persistent CONTROL socket (`/ws?control=1`) carrying `sessions`/`tabCreated`/`settings`/`extraKeys`/`fonts`/`ready(webApps,maxUploadBytes)` + all control sends (design D9)  |
| `wsGenRef`, `replayPendingRef`, `suppressInputRef` (~29, 73–74, 216–232)                  | app-level refs                                      | **TerminalPane** (component-local; the `gen` guard pattern stays verbatim)                                                                                                                                                                                                                                                    |
| `onTermData` report gate + `lastFocusAtRef` + window focus listener (~75–100)             | app-level, one gate                                 | **TerminalPane** — carried VERBATIM per pane (per-document `hasFocus()` + 1s grace window). Slot focus plays NO role (design D2, corrected). The `blockTermInputRef` mirror of `isBlocked()` also moves per-pane                                                                                                              |
| `useTerminal` host + `ref`/`instance`/`fit`/`refreshFont` (~134–146)                      | one instance                                        | **TerminalPane**                                                                                                                                                                                                                                                                                                              |
| Ctrl+Shift+C/V window-capture listener (INSIDE `useTerminal.ts` ~163–188, not App!)       | one global listener per instance                    | **App-level dispatcher** — remove from `useTerminal`; one capture listener routes to the focused pane's `PaneApi`. Each pane keeps `attachCustomKeyEventHandler` opt-out                                                                                                                                                      |
| `useFileUpload` (`dragActive`/`openPicker`/`uploadFile`/`pasteFromClipboard`, ~150–175)   | one instance bound to App's `wrapRef` + `sessionId` | **SPLIT** — hook instantiates per TerminalPane (its own `wrapRef`, its own `sessionId`, drag-drop uploads to the pane dropped on); the document-level image-paste listener inside the hook is hoisted/focus-gated so only one fires; `guardedOpenPicker`/`guardedPasteClipboard` stay in App but route via the focus registry |
| `uploadPasteRef` circular-dep break + `onPasteImage` (~128–132)                           | app-level                                           | **TerminalPane** (the cycle is pane-internal: terminal Ctrl+Shift+V → uploader → focus terminal)                                                                                                                                                                                                                              |
| exit overlay + `exited` state (~176, 494–515)                                             | full-area overlay; Reconnect = `location.reload()`  | **TerminalPane** — per-pane overlay; Reconnect rebuilds THIS pane's socket (never a page reload — it would nuke the sibling slot's state)                                                                                                                                                                                     |
| xterm mobile-neutralization effect (`disableStdin`, textarea readOnly, ~380–400)          | keyed on `[instance, mobileActive]`                 | **TerminalPane** (per instance). Also blur-on-mount when unfocused: `react-xtermjs` calls `instance.focus()` unconditionally on mount — the second pane must not steal focus                                                                                                                                                  |
| focus-follow effect (blur xterm under pane/chooser, refocus on terminal, ~370–378)        | app-level, single instance                          | **SPLIT** — App decides WHICH pane should hold focus (slot focus × overlays); pane exposes `focus()`/`blur()` via `PaneApi`                                                                                                                                                                                                   |
| visualViewport keyboard tracking + selection restore (~420–460)                           | app-level, uses `instanceRef`                       | **App** — but reads the FOCUSED pane's instance from the registry instead of `instanceRef`                                                                                                                                                                                                                                    |
| `useSoftKeyboard` + `#mobile-kbd` textarea (~178–200, JSX ~590)                           | app-level, closes over `sendInput`                  | **App** — unchanged home; its `sendInput`/`onImage`/`isBlocked` become stable closures reading the focused pane from the registry ref at call time (the hook re-binds on callback identity — keep them stable)                                                                                                                |
| `ExtraKeysBar` + `barRef`/`getMods` (~180, JSX ~576)                                      | app-level                                           | **App** — `send` routes to focused pane; armed/locked modifiers survive focus changes                                                                                                                                                                                                                                         |
| `useMobileGestures` (~186–200)                                                            | app-level, binds App's host+term                    | **TerminalPane** — per-pane host/term; tap also calls `setFocusedSlot`; App passes `openDrawer`/`setFontSize`/`focusKeyboard` down                                                                                                                                                                                            |
| `tabs`/`webApps`/`dirtyTabs`/`sheetTabId`/`newTabOpen` state + handlers (~40–70, 240–330) | fed by the single socket                            | **App** — fed by the CONTROL socket only                                                                                                                                                                                                                                                                                      |
| `switchSession`/`createTab`/`closeTab`/rename/recolor/url (~205, 306–360)                 | send on `wsRef`                                     | **App** — send on the control socket                                                                                                                                                                                                                                                                                          |
| `settings`/`extraKeys` hooks (~55–60)                                                     | send on `wsRef`                                     | **App** — control socket                                                                                                                                                                                                                                                                                                      |
| topbar/strip/drawer/panels/TabSheet JSX                                                   | app-level                                           | **App** (unchanged this stage)                                                                                                                                                                                                                                                                                                |

Invariant list for the stage-1 regression pin (spec: "Single terminal unchanged after refactor"):
reconnect replay restores the screen with zero typed junk; PTY resize on fit; Ctrl+Shift+C/V; drag-
drop + picker + clipboard upload; mobile keyboard IME flow; extra-keys bar; gestures + selection
handles; exit overlay; settings/theme/fonts sync; tab create/kill/rename from the strip and drawer.

Also in `terminal/touch.ts`: `lastSelection` (module-level, ~line 123) becomes instance-scoped —
e.g. a `TouchState` object created per pane and threaded to `selectRange`/`getSelectionEndpoints`/
`selection-handles.ts` — two terminals sharing it corrupts handle drags.
